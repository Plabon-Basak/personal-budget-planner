# Personal Budget Planner

A command-line budget planner that tracks your income and expenses, checks your savings goal, and visualizes spending as a pie chart.

## Features

- Set a monthly savings goal
- Add income and expenses by category
- View expenses grouped by category
- Calculate remaining budget
- Check progress toward your savings goal
- Visualize expenses with a Matplotlib pie chart

## Usage

```bash
pip install matplotlib
python app.py
```

Follow the prompts, then choose from the menu options to add expenses, view totals, or plot the expense distribution.

## Requirements

- Python 3.x
- `matplotlib`
